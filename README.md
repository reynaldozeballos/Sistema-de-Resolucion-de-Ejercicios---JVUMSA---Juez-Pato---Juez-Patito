## INSTALACIONES

YA DEBES TENER PYTHON y CHROME INSTALADO y si ya tienes, solo ejecutas el archivo 
`Instalador_de_librerias.bat` que va a instalar: 
```bash
pip install selenium
pip install webdriver-manager
pip install pyperclip
pip install pandas
```
## CONFIGURACIONES ANTES DE HACER CORRER EL CÓDIGO

Una vez instalado todo lo anterior, hay que configurar el ` DATOS.xlsx` poniendo en las columnas correspondientes:
# EJEMPLO
`TEN EN CUENTA QUE TIENES QUE PONER EL ENLACE DEL CONCURSO, NO DE: https://jv.umsa.bo/oj/ ` POR QUE si pones ese enlace no funcionará

configura el excel de la siguiente manera: 
| NOMBRE | CONTRASENA     | ENLACE DE PAGINA DEL PROBLEMA                |
| :-------- | :------- | :------------------------- |
| F-123-ABC | LOLPOTITOP | https://jv.umsa.bo/oj/contest.php?cid=**NUMEROCONCURSO**|

CUMPLIR CON EL ENLACE COMPLETO QUE SIEMPRE TENGA EL:ㅤ" **https://...** "

talvez es muy dificil de entender del enlace, pero tienes que entrar al concurso a resolver, es decir, haces click en: 
![Descripción de la imagen](https://i.imgur.com/9Zk2OhS.png)
una vez hecho CLICK en el concurso que quieres resolver te saldrá la ventana:![Descripción de la imagen](https://i.imgur.com/tLR8BTw.jpg)
y copias ese enlace todo completo y eso es todo
